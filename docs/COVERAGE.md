## Families

- **Room to connect** (`connect`): free grid capacity, hosting capacity or connection queues per substation, node or area (Grid capacity layer, site analysis). have 9, built 10, not published 10, blocked 0.
- **Every generating unit** (`units`): national registers of generating units (layer per country under Power plants). have 2, built 0, not published 0, blocked 0.
- **Live mix and CO₂** (`live_mix`): generation by source at the operator's own time step, and CO₂ per kWh where the operator publishes it (country cards). have 26, built 0, not published 0, blocked 0.
- **Redispatch and curtailment** (`congestion`): redispatch, countertrading, congestion-management costs and curtailment (country cards, agent catalogue). have 1, built 0, not published 0, blocked 0.
- **Wholesale prices** (`prices`): day-ahead and imbalance (or real-time) prices (Prices views, imbalance card). have 25, built 0, not published 0, blocked 0.
- **What consumers pay** (`retail`): household and business electricity and gas prices (retail colouring, country report). have 28, built 0, not published 0, blocked 0.
- **Emitters per installation** (`emitters`): verified CO₂ per installation (CO₂ per installation layer). have 28, built 0, not published 0, blocked 0.
- **Plants offline now** (`offline`): generating units out of service now (planned and forced). have 22, built 0, not published 0, blocked 0.
- **EV charging** (`ev`): public charge points (EV charging layer) and counts per country. have 1, built 0, not published 0, blocked 0.
- **Gas** (`gas`): gas flows, storage, LNG and prices. have 18, built 0, not published 0, blocked 0.
